# scripts/agent —— 一次性脚本的存放约定

这里放**临时/一次性**的辅助脚本，用来代替把脚本丢进 `%TEMP%` 或临时目录（那些地方会被清掉，下次就找不到当初是怎么做的了）。

和其它目录的分工：

- `scripts/` 根目录：**项目工具链**，被 `package.json` 或构建流程调用，改坏了会影响发布（如 `build-wiki.mjs`、`build-docs.mjs`、`postbuild-wiki-index.mjs`）。
- `scripts/agent/`：**助手写的一次性脚本**，不参与构建，不进 `package.json`。

约定：

1. 命名 `<日期>-<用途>`，例如 `2026-11-13-check-fullscreen.mjs`，从名字就能看出能删。
2. 脚本必须可重复执行且默认只读：验证、截图、探针类绝不写仓库文件；需要写 D1 的脚本把 SQL 单独放进同名 `.sql`，脚本只负责调用。
3. 不留密钥、token、cookie；要认证就走本地已登录的浏览器或环境变量。
4. 用完不必急着删，但每半年清理一次；判断标准是「这条脚本里的做法有没有已经写进 README / 某个文档」——写进去了就可以删。
5. 只在本机跑（Chromium/CDP、wrangler 登录态等），不要被 CI 引用。
